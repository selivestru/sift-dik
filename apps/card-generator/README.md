# SiftDIK Card Generator

Отдельный локальный инструмент на Vite + React + TypeScript. Игровой движок не требуется.

```sh
cd apps/card-generator
bun install
bun run dev
```

`bun run format` форматирует проект, `bun run format:check` проверяет форматирование, `bun run lint` запускает oxlint. `bun run typecheck` проверяет TypeScript. `bun run build` проверяет типы и создаёт `dist`; `bun run preview` запускает просмотр сборки.

Выберите Unit или Spell, введите название, характеристики и описание в редакторе, загрузите арт (PNG, JPEG, WebP). Выберите фракцию в табах: ДИКи, Качки, Снобы, СЕКСи или Другие. Для Unit включите нужные статические навыки переключателями; список поддерживает поиск. Для Spell выберите один из табов Slow, Fast, Burst (по умолчанию Slow). Каждый таб хранит собственные данные до перезагрузки страницы. Изображения обрабатываются в браузере и не отправляются на сервер.

Экспорт: PNG 1200×1600, 3:4, прозрачность вне рамки. Unit растягивается до этих пропорций; Spell имеет исходное соотношение 3:4. Арт кадрируется по центру. У Spell нет атаки и здоровья. Название, навыки и описание размещаются в таком порядке. Для Unit нижняя граница блока привязана к горизонтальной линии над верхними краями рамок атаки и здоровья: 84% высоты карточки (y = 1344 px при экспорте 1200×1600). От этой линии описание и остальные элементы растут вверх с внутренним отступом 10 px. Произвольного ограничения высоты текстового блока нет: длинный блок расширяется вверх до границы карточки под верхними значками. Для Spell короткий блок начинается под круглым артом; длинный сдвигается вверх, используя доступную высоту карточки; его высота рассчитывается по реальному количеству строк и рядов иконок. Для Unit один навык показывает иконку с названием в горизонтальной плашке, несколько — только иконки в плашках той же формы с золотой окантовкой. Иконки имеют размер 77,44 px. Внутренний отступ плашки — 16 px, промежуток между иконкой и названием — 16 px. Название навыка использует шрифт 64 px и выравнивается по центру видимых букв относительно иконки. Плашки имеют тонкую золотую окантовку и тёмный фон. Для Spell под названием отображается иконка и название выбранного типа заклинания. Под нижним блоком применяется лёгкое размытие и плавное затемнение фонового изображения. Текст и иконки рисуются поверх эффекта и остаются чёткими. Описание рисуется белым текстом с тенью, без прямоугольной подложки; у Spell тёмная панель является частью исходной рамки. Переполнение области названием, навыками и описанием блокирует экспорт; размер шрифта описания фиксирован — 44 px в итоговом PNG. Переносы учитывают ширину обычного и выделенного текста, а также иконок внутри описания. Длинное описание не уменьшает текст; при переполнении экспорт блокируется.

## Переиспользование

`src/generator/render.ts` не зависит от React. Дождитесь загрузки изображений через `loadImage` и шрифтов CardSans (обычного и жирного) и CardTitle (жирного). Вызовите `renderCard(canvas, data, { frame, art, faction, keywords, spellSpeeds })`, проверьте `descriptionFits`, затем `exportPng(canvas)` для получения Blob. Вызывающий код отвечает за валидные целые неотрицательные характеристики. `data.descriptionParts` — необязательный массив фрагментов описания (`DescriptionPart`): текст с флагом `highlighted` или навык с `id`. Если массив не передан, используется обычная строка `data.description`. `data.name` — необязательное название, `data.keywords` — массив идентификаторов из `src/generator/keywords.ts`. `images.keywords` — словарь загруженных иконок по имени файла. При выборе навыков все используемые иконки должны быть загружены. Для Spell передайте `data.spellSpeed` (`slow`, `fast`, `burst`) и `images.spellSpeeds` — словарь изображений по идентификатору скорости. Если тип не задан, используется Slow. Поле `keywords` у Spell игнорируется. Геометрия рамок находится в `src/generator/templates.ts`.

Предпросмотр использует ту же отрисовку, что экспорт. При экспорте создаётся отдельный canvas, чтобы изменение формы во время создания Blob не повлияло на скачиваемый файл.

Рамки предоставлены в корне репозитория и скопированы в `public/assets`. Локальный шрифт DejaVu Sans поддерживает кириллицу; условия использования приведены в `public/assets/FONT-LICENSE.txt`.

## Фракции и навыки

Фракции — отдельные настройки инструмента: `dik`, `aaa`, `ano`, `hot`, `other`. Снобы соответствуют Alpha Nu Omega (`ano`); они не подменяют Tri-Betas (`bbb`) из движка. SVG-эмблемы фракций созданы для этого генератора и не являются официальными логотипами Being a DIK. Их цвета — оформление инструмента.

В каталоге 39 статических навыков из указанной пользователем статьи, включая Заморозку, Отсчет и Посмертие. Скорости заклинаний выбираются отдельными табами только для Spell; триггеры и действия не входят в список навыков. Навыки являются визуальными настройками; выбор не применяет игровые эффекты и не проверяет их совместимость.

Иконки сохранены локально; происхождение указано в `public/assets/keywords/SOURCES.md`. Для Отсчета, у которого нет отдельного символа в исходной статье, используется собственный SVG-индикатор песочных часов. Неподвижность отображается символами запрета атаки и блокировки.

## Редактор описания

Поле поддерживает текст, переносы строк и два вида оформления:

- Выделите условие и нажмите «Золотой текст», чтобы придать ему золотой цвет и жирное начертание. «Обычный текст» снимает оформление выделенного фрагмента.
- Выберите навык в списке «+ Навык»: в позиции курсора появится его иконка и золотое название. Вставка в описание не включает отдельную плашку статического навыка.

Оформление сохраняется при переключении Unit / Spell и попадает в PNG. При вставке из буфера принимается только текст. Произвольный HTML не используется.

Размер и центр медальона фракции заданы по внутреннему металлическому диску каждой исходной рамки: Unit — область `(1147, 64, 268, 272)` в изображении 1483×2073; Spell — `(844, 55, 186, 186)` в изображении 1086×1448. При экспорте медальон масштабируется по обеим осям вместе с рамкой, заполняя ячейку без прозрачных полей внутри SVG. Золотой обод исходной рамки остаётся снаружи медальона.
